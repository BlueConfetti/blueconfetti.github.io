A small sample handbook as it looks in Confluence, next to the ZIP Flint Markdown Export made from it. Pick a page or a file to compare them.

This sample needs JavaScript to browse. Download the sample ZIP to open the files yourself.

What to look for

  • Front matter at the top of each file: title, source URL, breadcrumb, labels, author, and dates.
  • Relative links between pages, so the files still link to each other in your editor or repository.
  • Images saved beside the page that uses them, in its .assets folder.
  • manifest.json describing every page, and all-pages.md with the whole tree in one file.

Every file shown here was produced by Flint Markdown Export from made-up pages. Read the full guide.
