How it works in Confluence

  1. Insert the Table Glide macro on a page.
  2. Paste or build an ordinary Confluence table inside it. The first row is the header.
  3. Publish. Each viewer gets their own search, filters, sorting, and pages, and the stored page never changes.

Columns with repeated values and no more than 50 distinct values get a filter. Search, filters, and sorting cover the whole table before it is split into pages of 50 rows. Read the full Table Glide guide or follow the table filtering walkthrough.
