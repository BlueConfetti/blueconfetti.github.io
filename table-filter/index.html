Table Glide

Find the rows that matter, with your table’s native formatting intact.

This app is being prepared for Marketplace release and is not yet available for purchase.

Try the interactive demo →

Set up a table

  1. Once available, ask your Confluence administrator to install the app from the Atlassian Marketplace and start a trial or subscription.
  2. Edit a Confluence page and insert the Table Glide macro using the slash menu.
  3. Add or paste an ordinary Confluence table inside the macro body. Use the first row for column headings.
  4. Publish the page. Viewers can now use search, column filters, sorting, and page controls.

Search and filter

Search checks every column across the whole table, regardless of the page you are viewing. Matching ignores letter case. Search applies after a short pause in typing.

Columns with repeated values and no more than 50 distinct values get a filter dropdown. Choose several values to match any of them within one column. Filters across different columns must all match. Empty cells appear as “(empty)”.

Sort and browse

Choose a column and ascending or descending order. Numbers sort by value, text uses natural ordering, and blank cells stay at the bottom. Choose “Original order” to restore the table’s saved order.

Results appear in pages of up to 50 rows. Previous page and Next page move through the results. Search, filters, and sorting apply to all rows before pagination, and changing them returns you to the first page.

Your page stays unchanged

Controls affect only your current view. Other viewers can choose their own filters. Reloading resets your view. The complete original table stays stored on the Confluence page.

Limits and troubleshooting

  • The macro uses the first top-level table inside its body; the first row is treated as the header.
  • Merged cells disable interactive filtering. Unmerge them to enable the controls.
  • A missing or inactive license shows the original table with a notice. Ask your administrator to start a trial or renew.
  • High-cardinality columns do not get a dropdown; use search instead.
  • PDF exports include the complete original table, independently of your interactive view. Confluence controls PDF layout and wrapping. Word export has not yet been verified.

Privacy and support

The app requests no permission scopes and sends no table data to BlueConfetti. Read the privacy policy or contact support.
