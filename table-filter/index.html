Search and filter Confluence tables

Explore native tables with rich content, reusable views and CSV/XLSX downloads. Each reader controls their view without changing saved table data.

View on Atlassian Marketplace · Try the basic demo · Guides and worked examples

Set up a table

Ask your Confluence administrator to install Flint Table Filter and start a trial or subscription. Edit a page, insert the macro and add an ordinary Confluence table inside it. Macro settings let you choose Automatic, First row or No header interpretation. Source table selects a later top-level native table, starting at 1. Choose a settings section and adjust starting filters, search, sort, layout, summaries and numeric formats. The live preview shows five matching rich rows, detected types, warnings, numeric summaries and group totals. Save settings updates the macro in the editor; publish the page to share the changes. Cancel discards the draft.

Search, filter and sort

Search checks every column across the whole table before pagination. Filters offers exact included/excluded values and text, number or date conditions. Larger value sets have searchable ten-choice pages. Facet counts reflect the other constraints. Choose dot/comma decimal or date interpretation when needed. Relative dates follow your device's local day.

Advanced groups combines AND/OR expressions up to four group levels, five children per group and 100 total nodes. Save each complete rule to apply it. Copy the expression into Default advanced filter groups in the macro settings to publish it as the starting view.

Header Sort cycles ascending, descending and original order; hold Shift to add a priority. Header Filter opens the native column editor. Sort also provides ordered multi-column rules. Columns controls visibility, display order and widths. Hiding columns changes presentation and does not restrict access to source data.

Worked examples: combine AND/OR filters · fix ambiguous numbers and dates · run a weekly status review.

Summaries and presentation

Summary calculates across all matches before pagination. Group by a column, rank groups by label/count/numeric totals and use Show rows for exact group focus. Clear focus to return to the wider result. Choose 25, 50 or 100 rows per page, jump directly to a page or Expand table.

Open Saved views and presentation for density, sticky headers, horizontal column pinning, conditional backgrounds and grouped rich rows. Group headings show full-group subtotals even across pages. Show native rich content provides recovery for unsupported rich output or hosted-reader failure.

Worked examples: group rows and total them · read wide or long tables · highlight cells.

Reusable views

Enter a name and Save personal view to retain query, layout, types/formats, grouping/focus and presentation settings in this browser for your account and macro. Apply view starts at page one. Delete personal view removes the local entry. Up to 20 named views are supported; they do not synchronize across devices. Reset view restores author defaults without deleting saved views.

Prepare shared view settings creates text for the author. Paste it into Shared reader views in macro settings and publish. Preparing or applying a view does not edit the page. Settings include search/filter values; share only values you intend page readers to see. Table/header changes may invalidate older views.

Worked examples: save a personal view · publish shared views.

Downloads and document exports

Export offers Current result and Original table. Current result includes all matching data rows across pagination, exact group focus, visible columns and current group/sort order. Original includes every selected source-table row and column in source order. Display-only group headings and subtotals are excluded from data files.

CSV and XLSX contain extracted text rather than rich formatting. CSV prefixes formula-like values with an apostrophe, changing the exported data; this is not a universal spreadsheet-security guarantee. XLSX stores every value as text, preserving leading zeros, Unicode and locale number strings. Format limits produce an explicit message instead of silent truncation. Native CSV copy remains available.

Confluence PDF and Word retain the complete original macro body, independent of filters, hidden columns and reader merged-cell expansion. Page history preserves the body and configuration saved with each version and can display the interactive reader. Confluence controls document layout, wrapping and some status-label truncation.

Worked example: export results to CSV or Excel.

Supported sources and recovery

Native rich content includes status labels, mentions, dates, bold text and ordinary links. Safe merged cells expand into logical rows; a notice explains that covered values repeat and totals count them. Unsafe or excessive spans keep the original native body.

This release uses native top-level tables inside the macro. Reports/excerpts and generated output from other apps are outside this release, as are pivots, charts, formulas, joins, imports and editing. An inactive/missing license shows the complete original body without interactive controls.

Worked examples: choose source tables and headers · troubleshoot missing controls and unexpected results.

Privacy and support

Processing and file creation run in the browser. Personal views use browser-local settings; shared views live in the page. No Confluence product-data scopes, Forge storage or external egress are added. Inline styles support the hosted reader. BlueConfetti does not receive table content.
