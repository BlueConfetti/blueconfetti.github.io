FLINT TABLE FILTER · HOW-TO

Save a personal table view for your daily work

If you open the same table every morning and rebuild the same filters, save them once. A personal view keeps your filters, sort, columns and presentation for one table in your browser.

What you will end with: a view named “My open work” that shows Priya Shah’s 4 unfinished tasks, with Team and Owner hidden and the earliest due date first, restored in two clicks after a reload.

Before you start

This guide uses the project tracker from the weekly status review. Imagine you are Priya Shah. Any reader can save personal views; no edit permission is needed.

Step 1: Build the view

  1. Choose Filters, then Owner. In Matching values, choose Priya Shah.
  2. Choose Status, set Condition to Is not one of and exclude Done.
  3. Choose Columns and clear Team and Owner. The button reads Columns (5/7).
  4. Sort Due ascending.

Step 2: Save it

  1. Open Saved views and presentation.
  2. Enter My open work in View name and choose Save personal view.

The status line confirms Saved “My open work” in this browser. Saving again with the same name, in any capitalization, replaces that view.

Step 3: Reload and apply

Reload the page. Unsaved changes are gone and the table returns to the author’s starting view. To bring yours back:

  1. Open Saved views and presentation.
  2. In Reader view, choose Personal: My open work.
  3. Choose Apply view. The status reads Applied “My open work”. and the table starts at page one.

Step 4: Reset without losing it

Reset view restores the author’s defaults and leaves your saved views alone. Choosing Author default in Reader view and Apply view does the same. Apply your view again at any time.

Step 5: Delete it

Choose Personal: My open work in Reader view, then Delete personal view. The status reads Deleted “My open work”. Only personal views can be deleted here; shared views are managed by the page author.

What a view keeps

Contents of a personal view
Saved in the viewNot saved
Search text, column filters and conditions, advanced groupsThe page number you were on
Column types, number formats and date formatsTable rows or cell values
Sort order, hidden columns, column order and widthsChanges to the source table
Rows per page, summary, grouping, group order and group focusAnything for other tables or pages
Row density, sticky header, pinned columns, conditional formatting and grouped rich rowsViews saved in another browser or on another device

Where personal views live

  • In this browser’s local storage, for your Atlassian account, this site, this macro and this table layout. Up to 20 named views per table, with names of up to 80 characters.
  • They do not follow you to another browser, device or browser profile. Private windows and clearing site data remove them. If storage is blocked, the section reports Personal view storage is unavailable for this browser session.
  • Views contain your search and filter values. On a shared computer, delete views that contain sensitive values.

When the table changes

Adding or removing rows keeps views working. If an editor adds PRJ-125, a task for Priya due 19 November, “My open work” shows five tasks: PRJ-101, PRJ-116, PRJ-109, PRJ-125, PRJ-123.

Changing the layout is different. Renaming, adding, removing or reordering header cells, changing the Header row setting, or replacing the table gives the table a new layout, and views saved for the old layout no longer appear in Reader view. Build the view again and save it. Copying the macro to another page does not copy personal views.

If Save personal view or Apply view does nothing

The status line explains what to finish first:

  • Wait for the search to finish before saving or applying a view.
  • Apply or discard advanced filter changes before saving or applying a view.
  • Correct invalid filters before saving or applying a view.
