FLINT MARKDOWN EXPORT · HOW-TO

Save export profiles for repeatable monthly or project exports

Set up output settings once, give them a name, and get the same files every time you export.

Finished result

Two named profiles, “Engineering Git” and “Project context”, that restore output settings in one step. You still choose the pages each time.

What a profile keeps

Saved in a profileChosen each time
Preset, page links, panels and filename patternSource, space and selected pages
Add YAML frontmatter and the frontmatter fieldsInclude other attachments
Custom metadata valuesIn this window or In background
A previous manifest for comparison

Profiles do not schedule exports. A recurring export is a task you repeat, using the profile to keep its output consistent.

Create the profiles

  1. Open Apps → Export to Markdown on any page. Choose Git documentation and, in Advanced settings, enter team=Platform under Custom metadata.
  2. Choose Saved profiles in the header. Under My output profiles, enter Profile name “Engineering Git” and choose Save current output settings.
  3. Choose Back to selection, choose AI context, clear author and last_updated_by under Frontmatter fields, and save a second profile named “Project context”.

Use a profile next month

  1. Open the root page, choose Apps → Export to Markdown and the source you need.
  2. Choose Saved profiles, then Use profile beside “Engineering Git”. The workspace returns to selection with the saved settings and custom metadata restored.
  3. Set Include other attachments, which the profile does not store.
  4. Optionally load last month’s manifest.json under Compare with a previous export; see comparing exports.
  5. Export as usual.

If you choose a preset after loading a profile, the preset replaces the loaded output settings; custom metadata text is kept.

Replace or delete a profile

  • Replace: change the settings, enter the same profile name and choose Save current output settings. The profile with that name is replaced.
  • Delete: choose Delete beside it. Other profiles are unaffected.

Limits

  • Each person can keep up to 20 profiles. Saving a 21st shows Keep up to 20 profiles. Delete one before adding another.
  • Names are 1 to 60 printable characters.
  • Profiles belong to you. Colleagues do not see your profiles; to share settings, agree the values and save the same profile in each account.
  • Profiles stay until you delete them and are stored in Atlassian-hosted Forge storage. They include custom metadata values, so keep secrets out of them.

This guide describes the released profile controls; it does not include downloadable output, because a profile changes settings rather than files.
