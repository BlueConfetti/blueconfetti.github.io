FLINT TABLE FILTER · USE CASE

Build a content review queue from a Confluence table

Knowledge bases stay trustworthy when someone reviews each page on schedule. Keep the schedule in a table and work it as a queue: what is due this month, what is late, and what has nobody to review it.

What you will end with: from 24 tracked documents, the 14 unapproved reviews due in November 2026, the 6 that were already late on 9 November, and the 4 documents without an owner, plus a starting view that shows the current month to every reader.

What this queue does and does not do

Editors maintain the table: one row per document, with its owner, team, last review and next review date. Flint Table Filter turns that table into queues. It does not find stale pages, read page history, change review dates or send reminders.

  1. Edit a Confluence page and insert the Flint Table Filter macro.
  2. Inside the macro, add a native Confluence table whose first row is a header row with the column names from content-review-queue.csv, then enter or paste the data rows. If you paste from a spreadsheet, check that the result is an editable Confluence table rather than an image or an embedded file.
  3. Publish the page. Search, Filters, Sort, Columns, Summary, Export, Expand table and Reset view appear above the published table.

The worked examples use Monday 9 November 2026 as today. Relative date presets follow each reader’s device calendar, so on another day the same rule matches different rows. Where it matters, a fixed date range that reproduces the published result is included.

Queue 1: Reviews due this month

  1. Choose Filters, then Review due. Set Condition to Relative date and Date preset to This month.
  2. Choose Review status, set Condition to Is not one of and exclude Approved.
  3. Sort Review due ascending.

Owners can then add their own name in a filter and save the result as a personal view called “My reviews”.

What to know

  • Use native Confluence date chips or YYYY-MM-DD text for dates. Day-first or month-first text dates need an explicit format; see ambiguous dates.
  • If owners are @mentions, filters compare the mention text Confluence stores, which can include the @ sign. Contains with part of the name matches either way.
  • A filtered queue does not hide documents from anyone. Every row remains in the page.
