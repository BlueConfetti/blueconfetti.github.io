FLINT TABLE FILTER · TROUBLESHOOTING

Troubleshoot missing controls, empty results and unexpected table counts

Most problems come from the table source, a filter value, or a saved setting that no longer matches the table. Start with the message you see, then work through the checks below.

Quick checks: read the count line under the controls (for example 12 of 24 rows), the tags above the table, any Author defaults currently applied line, any group focus banner and the notices under the table. Together they explain almost every unexpected result.

No rows match

An empty result shows No matching rows with Clear search and Reset view. Work through these causes:

  • A filter combination. Filters on different columns must all match. Read the tags above the table and remove one at a time. To ask “this or that” across columns, use advanced groups.
  • An invalid value. Check your filter values lists it, for example Due: Enter a valid date as YYYY-MM-DD or in the selected date format. for 11/09/2026 in a YYYY-MM-DD column. That condition matches nothing until corrected; see number and date formats.
  • An invalid advanced rule. Check your advanced filters names the group and rule. The whole expression matches nothing until it is fixed.
  • A relative date. Presets follow your device’s calendar. The reference date is shown under the condition.
  • An exact value. Is one of compares the full cell text, including capitalization and extra words. Use Contains for partial text.
  • Group focus. No matching rows in the focused group means the focus is still active. Choose Clear group focus.

The count or total is not what you expected

  • Group focus is active. The count line reads, for example, 16 focused rows · 48 matching before group focus · 64 total rows, and a banner names the focused group.
  • Author defaults apply. The page may open filtered. The line Author defaults currently applied lists them, and Reset view returns to them rather than to the unfiltered table.
  • The header row is read as data. If the notice says No header row detected, the first row counts as a data row. Format it as header cells or set Header row to First row is header.
  • A search matched a hidden column. Search covers every column, visible or not.
  • Some cells are not numbers. Summaries list numeric, blank and unreadable cells; only numeric cells are totaled.
  • Merged cells repeat values. Each covered position gets a copy, as in the example below.

A saved view is missing or will not apply

  • Personal views live in one browser. They do not appear in another browser, device, profile or private window, and clearing site data removes them. Personal view storage is unavailable for this browser session. means the browser blocks storage.
  • The table layout changed. Renaming, adding, removing or reordering header cells, changing Header row, or replacing the table means personal views saved for the old layout no longer appear. Shared views report These views belong to a different table or header layout. Save them again for this table.
  • Something is still pending. Saving and applying wait for the search to finish, for any advanced rule draft to be applied or discarded, and for invalid filters to be corrected. The status line says which.
  • The view no longer fits the table. Reader view could not be applied appears above the table with the reason. Rebuild and save the view.

See personal views and shared views.

The starting view shows a warning

Check the table's default view lists each author setting that was skipped and why. For example, after Due is renamed: The saved default sort was skipped because its header name is missing or blank. Update the macro settings to use a current, unique header name. Copied advanced filters are skipped as a whole rather than partly applied. Update the header names in the macro settings, or copy the advanced settings again, then publish.

Rich content or links look wrong

Choose Show native rich content to display the table with Confluence’s own rendering, then Show interactive table to return. If a link reports The link could not open. Use native rich content to follow it., follow it from the native view.

A download differs from the screen

Current result follows your filters, group focus, visible columns and sort; Original table ignores them. CSV prefixes formula-like values with an apostrophe. Confluence PDF and Word exports always contain the complete original table. See CSV and Excel exports.

Start again

Reset view restores the author’s starting view and keeps your saved views. Choosing Author default in Reader view and Apply view does the same. A reload also clears unsaved changes.

Contact support

If none of this explains the problem, contact support with the exact message, what you expected, your browser, and a small example table with private information removed. Please do not send confidential page content.
