FLINT TABLE FILTER · HOW-TO

Combine AND/OR filters for questions a simple dropdown cannot answer

Column filters answer “this and that.” Some questions need “this and (that or the other).” Advanced groups let you write that expression directly, nest it, and publish it as the page’s starting view.

What you will end with: Engineering AND (Blocked OR due this week) returning 5 of 24 tasks, a nested version that adds an estimate threshold and returns 4, and the expression published as the table’s default.

Why separate column filters fall short

In the column filters, several values chosen for one column match any of them, and filters on different columns must all match. Choosing Team Engineering, Status Blocked and Due This week therefore asks for Engineering tasks that are blocked and due this week. In the sample tracker, none are. The question is really Engineering AND (Blocked OR due this week).

The worked examples use Monday 9 November 2026 as today. Relative date presets follow each reader’s device calendar, so on another day the same rule matches different rows. Where it matters, a fixed date range that reproduces the published result is included.

How advanced groups combine

  • Match groups joins the top-level groups: All groups (AND) or Any group (OR).
  • Each group has its own Match rules in group setting: All rules (AND) or Any rule (OR). Nested groups keep their own choice too.
  • Search and column filters still apply alongside the advanced groups; all must match.

Step 1: Build Engineering AND (Blocked OR due this week)

  1. Choose Filters, then Advanced groups. Keep Match groups as All groups (AND).
  2. Choose Add group. Set Rule column to Team, Rule condition to Equals and Rule value to Engineering. Choose Save rule. This is group 1.
  3. Choose Add group again. Create Status, Equals, Blocked and save it. This is group 2.
  4. Set Match rules in group 2 to Any rule (OR).
  5. Choose Add rule to group 2. Set Rule column to Due, Rule condition to Relative date and Rule date preset to This week. Save the rule.

The panel shows each group with its match setting and numbered rules. In outline:

Group 1   Match rules in group 1: All rules (AND)
  1.1. Team equals Engineering (Text)
Group 2   Match rules in group 2: Any rule (OR)
  2.1. Status equals Blocked (Text)
  2.2. Due: This week (Date, YYYY-MM-DD)

Step 2: Nest a third level

Suppose the meeting only cares about this week’s work if it is estimated at three days or more: Engineering AND (Blocked OR (due this week AND Estimate at least 3)).

  1. Choose Remove rule 2.2 to remove the plain due-this-week rule.
  2. Choose Add nested group to group 2. Create Due, Relative date, This week and save it. The nested group is group 2.2 and starts as All rules (AND).
  3. Choose Add rule to group 2.2. Set Rule column to Estimate, keep Rule type as Number, set Rule condition to At least and Rule value to 3. Save the rule.

Step 3: Publish it as the starting view

  1. Choose Copy advanced filter settings. Copy everything in Advanced filter settings.
  2. Edit the page, open the macro settings, choose Column filters and advanced rules and paste into Default advanced filter groups.
  3. Starting view preview counts the matches. For the Step 1 expression it reports 5 of 24 rows match. Choose Save settings and publish.

Only the applied advanced groups are copied; search, column filters, sorting and layout are separate settings. The copied text names columns by header and stores relative presets, not dates:

If a header named in the settings is later renamed, readers see Check the table's default view, and the advanced default is skipped rather than partly applied. Build the rule again and copy fresh settings.

Limits and behavior

  • Up to 5 top-level groups and 5 rules or nested groups in each group, nested up to four levels, with at most 100 groups and rules in total.
  • A draft applies only after Save rule. If you leave the panel with a draft open, the toolbar shows An advanced rule has unsaved changes. with Continue editing rule.
  • Each rule keeps its own type and format. A number rule has Rule number format; a date rule has Rule date format.
  • If any rule is invalid, the warning Check your advanced filters names it, and the whole expression matches no rows until you fix it. It never applies half an expression.
