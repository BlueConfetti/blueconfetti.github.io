How to filter a Confluence table

Turn a long project table into a view you can search and narrow without changing the saved page.

Confluence table capabilities can vary by context. When you want viewers to search and filter an ordinary table in a published page, Flint Table Filter provides controls around the table. Try the interactive launch tracker with fictional data before setting it up.

Example: find launch tasks that need attention

Imagine a tracker with Task, Team, Status and Due columns. You want to see work for the Engineering team that is either blocked or in progress, then find a particular task.

  1. On an editable Confluence page, insert the Flint Table Filter macro and place an ordinary table inside it, with column headings in the first row. Publish the page.
  2. In the published table, select Engineering in the Team filter. In Status, select both Blocked and In progress. Multiple values in one column match either value; filters on different columns must both match.
  3. Type a distinctive task name into search. Search checks every column in the whole table, ignoring case. Choose a column and direction to sort the matching rows, then use the page controls if needed.

Search, filters and sorting apply before results are divided into pages of up to 50 rows. Each viewer’s choices affect their own view, reset on reload and leave the saved table unchanged. Native table formatting remains visible.

Why is a filter missing?

A dropdown appears for a column with repeated values and no more than 50 distinct values. A column full of unique task names may not have one; use whole-table search instead. If the table contains merged cells, Flint Table Filter displays the plain table without interactive controls. Unmerge the cells to use them.

Does sorting change the page for everyone?

No. Sorting changes only your current view. Select original order to return to the saved order, or reload to reset the controls. Sorting uses one column at a time, with natural ordering for text and numeric ordering for numbers.
