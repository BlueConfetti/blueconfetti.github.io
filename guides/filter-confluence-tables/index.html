How to filter a Confluence table

Turn a long project table into a view you can search and narrow without changing the saved page.

When you want viewers to search and filter an ordinary table in a published Confluence page, Flint Table Filter provides controls around the table. Try the basic interactive launch tracker with fictional data before setting it up. The app also supports the typed filters, reusable views and multi-column sorting described below.

Example: find launch tasks that need attention

Imagine a tracker with Task, Team, Status and Due columns. You want to see work for the Engineering team that is either blocked or in progress, then find a particular task.

  1. On an editable Confluence page, insert the Flint Table Filter macro and place an ordinary table inside it, with column headings in the first row. Publish the page.
  2. Open Filters in the published table and choose the Team column, then select Engineering from its matching values. Choose Status and select both Blocked and In progress. Multiple values in one column match either value; filters on different columns must all match.
  3. Type a distinctive task name into search. Search checks every column in the whole table, ignoring case. Open Sort and choose Due with the required date interpretation and order, then use the page controls if needed.

Search, filters and sorting apply to the whole table before pagination. Choose 25, 50 or 100 rows per page; 50 is the ordinary default. Each reader controls their own view while the stored table stays unchanged. Native status labels, mentions, dates and links remain visible.

Filter unique values, dates and numbers

Every column can be filtered, including columns with unique values. Small value sets use a dropdown; larger sets have searchable choices in pages of ten. Open Filters, or a column header’s Filter action, to include or exclude exact values or apply text, number and date conditions. Choose explicit decimal and date interpretation when the source format is ambiguous.

For a question such as Engineering work that is blocked or due this week, use Advanced groups to combine AND/OR rules. Relative dates follow your device’s local calendar day.

Does sorting change the page for everyone?

No. Sorting changes only your current view. A header’s Sort action cycles ascending, descending and original order; hold Shift to add a sort priority. The Sort panel also lets you add and reorder multiple sort columns. Choose Restore original order there to remove the sorting rules. Text uses natural ordering; number and date columns use their configured interpretation.

Keep a view for next time

Unsaved reader changes are temporary. Open Saved views and presentation, name the view and choose Save personal view to keep its settings in this browser for your account and macro. After a reload, choose Apply view to restore it. Personal views do not synchronize across devices.

Reset view restores the author’s published defaults without deleting personal views. Authors can also publish named shared views through macro settings; readers can apply those choices without editing the page. Hiding columns changes the presentation and does not restrict access to source data.

What if controls are unavailable?

The macro works with native top-level tables inside its body. A missing or inactive app license leaves the complete original body visible without interactive controls. Safe merged cells expand into logical rows for filtering, with a notice that covered values repeat and can affect totals. Unsupported or excessive spans retain the original native body. Reports, excerpts and tables generated by other apps are outside this release.

If rich output cannot be displayed, use Show native rich content where offered. Check the setup instructions for source-table and header settings, or contact support with a small example that has private information removed.
