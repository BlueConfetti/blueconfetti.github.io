FLINT TABLE FILTER · USE CASE

Review vendors and upcoming contract renewals in Confluence

A vendor directory in Confluence can still tell you what renews next, what it costs and who owns it, without scrolling across ten columns.

What you will end with: a compact directory layout with Vendor pinned, the 14 contracts renewing within 90 days of 9 November 2026 (two contracts already ending are left out), and annual values totaled by category: $350,400 in all, led by Infrastructure at $111,300.

Before you start

Annual value uses a currency symbol and thousands separators, such as $84,000. Flint Table Filter reads these as numbers, so the column supports numeric conditions, sorting and totals.

  1. Edit a Confluence page and insert the Flint Table Filter macro.
  2. Inside the macro, add a native Confluence table whose first row is a header row with the column names from vendor-directory.csv, then enter or paste the data rows. If you paste from a spreadsheet, check that the result is an editable Confluence table rather than an image or an embedded file.
  3. Publish the page. Search, Filters, Sort, Columns, Summary, Export, Expand table and Reset view appear above the published table.

The worked examples use Monday 9 November 2026 as today. Relative date presets follow each reader’s device calendar, so on another day the same rule matches different rows. Where it matters, a fixed date range that reproduces the published result is included.

Step 1: Lay out the wide directory

Ten columns rarely fit in a page. Shape the view first so the renewal review is readable.

  1. Choose Columns and clear Contract ID and Notes. The button reads Columns (8/10). Hidden columns still take part in search and filters.
  2. Set Column to move to Renewal date and choose Move earlier until it follows Vendor.
  3. Under Column widths, set Width for column to Vendor and Column width to Standard (200 px).
  4. Open Saved views and presentation. Set Row density to Compact and, under Pin columns while scrolling horizontally, select Vendor. Vendor names stay in view while you scroll to Owner and Status.

Step 2: Find renewals in the next 90 days

  1. Choose Filters, then the Renewal date column. Set Condition to Relative date, Date preset to Next N days and Number of days to 90. On 9 November the window runs to 6 February 2027, including today.
  2. Choose Status, set Condition to Is not one of and exclude Ending. Fjord Translation and Xenon Print Services renew inside the window but are already being ended.
  3. Sort Renewal date ascending.

The app cannot subtract a notice period from a renewal date; if you need to filter on notice deadlines, keep a Notice deadline date column in the source table.

Step 3: Compare values by category

  1. Choose Summary. Set Summarize column to Annual value.
  2. Set Group rows by to Category and Group order to Highest sum first.

The summary covers the 14 matching contracts: a sum of 350,400, from 4,800 to 84,000. Currency symbols are ignored in totals, so the summary shows plain numbers.

What to know

  • Values are not converted between currencies. If a column mixes $, € or £, the summary shows Mixed numeric units; keep one currency per column or add a currency column and group by it.
  • The app does not send renewal reminders or change contract data.
  • Hidden columns are not access control. Contract IDs and notes remain in the page for every reader.
