FLINT TABLE FILTER · HOW-TO

Fix number and date filtering when formats are ambiguous

09/11/2026 is 9 November in one office and 11 September in another. 1.250 is one and a quarter in one locale and twelve hundred fifty in another. Tell the table which you mean before you filter, sort or total.

What you will end with: the Received column read as day-first dates, so a 1 to 15 November range matches 4 samples, and the Weight column read with comma decimals, so its total is 2,271.25 g from 8 readable cells instead of 3.25 g from 2.

How the app detects types

  • Number when every non-blank cell reads as a dot-decimal number. Thousands separators must group three digits; $, €, £ and % are allowed.
  • Date when every non-blank cell is a YYYY-MM-DD date. Native Confluence date chips read as YYYY-MM-DD.
  • Text otherwise. Day-first or month-first text dates and comma decimals are never detected automatically.

In the sample, Received and Weight (g) are detected as Text, and Cost as Number.

Dates: choose the format before filtering

  1. Choose Filters, then Received.
  2. Set Treat column as to Date and Date format in table to DD/MM/YYYY.
  3. Set Condition to Between, then enter 2026-11-01 and 2026-11-15 in From (inclusive) and To (inclusive). Values can be typed as YYYY-MM-DD or in the selected format.

Sorting

Sort Received ascending after setting DD/MM/YYYY: S-03, S-10, S-01, S-09, S-02, S-05, S-04, S-08, S-07, S-06. Valid dates come first in date order, then cells that are not dates, and blank cells stay at the bottom in either direction. Left as Text, the same sort compares characters: S-09, S-02, S-04, S-03, S-08, S-10, S-01, S-05, S-07, S-06, which puts 5 November before 28 October.

Numbers: choose dot or comma decimals

Choose Weight (g) in Filters, set Treat column as to Number, and choose Number format in table and values. The format applies to cells and to the values you type, to sorting and to numeric summaries.

With comma decimals, Weight At least 1 matches 6 samples (S-01, S-02, S-04, S-05, S-08, S-09); with dot decimals only S-04 and S-05 match. A tag above the table, Comma decimals: “Weight (g)”, reminds readers which format is active. Type filter values in the same format: with comma decimals, enter 1,5, not 1.5.

Totals

Choose Summary, set Summarize column to Weight (g) and Summary number format to 1.234,56 (comma decimal):

Totals display in your browser’s number format. Blank and unreadable cells are excluded, and the counts show how many were left out, so an unexpectedly small total is easy to spot. The Cost column, detected as Number, totals 3,514.24 from 9 cells.

Relative dates use the device calendar

Messages you may see

Invalid values appear under Check your filter values, and that condition matches no rows until corrected:

  • Enter a valid number. For example, 1,5 in a dot-decimal column.
  • Enter a valid date as YYYY-MM-DD or in the selected date format.
  • The lower bound must not exceed the upper bound.

Publish the right formats

An author can store number formats for every reader in Default numeric columns, one exact header per line, such as Weight (g) = comma. Date formats are chosen per default filter in its date format in table and values setting. The most reliable fix is in the source: use native date chips or YYYY-MM-DD, and one decimal style per column.
