FLINT TABLE FILTER · USE CASE

Make an equipment inventory easier to search and review

Inventories grow into long tables. Find one device in seconds, spot equipment nobody is assigned to, list warranties ending soon, and hand the list on without losing the zeros at the start of each asset ID.

What you will end with: asset 004205 found by search, 12 devices without an assignee (including one marked In use), and the 15 non-retired devices whose warranty ends between 1 November 2026 and 31 March 2027, exported with IDs such as 004142 intact.

Before you start

Asset IDs such as 004205 look like numbers, so Flint Table Filter detects the Asset ID column as a number column. That matters for exact matching and for exports, as shown below.

  1. Edit a Confluence page and insert the Flint Table Filter macro.
  2. Inside the macro, add a native Confluence table whose first row is a header row with the column names from equipment-inventory.csv, then enter or paste the data rows. If you paste from a spreadsheet, check that the result is an editable Confluence table rather than an image or an embedded file.
  3. Publish the page. Search, Filters, Sort, Columns, Summary, Export, Expand table and Reset view appear above the published table.

The worked examples use Monday 9 November 2026 as today. Relative date presets follow each reader’s device calendar, so on another day the same rule matches different rows. Where it matters, a fixed date range that reproduces the published result is included.

Find one device

Type 004205 in Search table. Search looks for the text anywhere in any column, ignoring case, so the table shows one row: a desk phone assigned to Gabriel Moreau. Partial text works too: 4205 finds the same device.

For an exact match, open Filters and choose Asset ID. Because the column is detected as a number, Equals 4205 also matches 004205: both are the number 4205. If your IDs must match character for character, set Treat column as to Text and enter 004205; with Text, 4205 matches nothing.

This inventory has 48 distinct IDs, so Is one of offers a dropdown. Once a column has more than 50 distinct values, it switches to a searchable list of ten values per page with Find a value.

Find unassigned equipment

  1. Choose Reset view, then Filters.
  2. Set Column to Assigned to and Condition to Is empty.

Twelve devices have no assignee. To see why, open Summary and set Group rows by to Status: 8 are In stock, 3 are Retired and 1 is In use. Choose Show rows: “In use” to find the record that needs fixing.

Review warranties ending this winter

  1. Choose Reset view, then Filters.
  2. Choose Warranty end, set Condition to Between, and enter 2026-11-01 in From (inclusive) and 2027-03-31 in To (inclusive).
  3. Choose Status, set Condition to Is not one of and exclude Retired.
  4. In the Warranty end header, choose Sort once for ascending order.

Export the list with IDs intact

  1. Choose Columns and clear Location. The button reads Columns (5/6).
  2. Choose Export. Keep Export scope as Current result.
  3. Choose Download XLSX for a spreadsheet, or Download CSV for another system.

Both files contain 004142 exactly. The difference appears when a spreadsheet app opens them: a CSV has no column types, so an app can convert 004142 to the number 4142 unless you import that column as text. The XLSX stores every value as text, so the leading zeros stay.

What to know

  • Search and filters include hidden columns. Hiding Location does not stop a search for “Berlin” from matching.
  • The table is the record. Flint Table Filter does not discover devices or sync with an asset system; editors keep the rows current.
  • Hidden columns and filters change presentation only. Readers can still see the whole table, and Confluence PDF and Word exports include every row and column.
