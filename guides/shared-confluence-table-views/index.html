FLINT TABLE FILTER · HOW-TO

Publish shared table views for different teams

One tracker, several audiences. Instead of copying the table for each team, publish named views on the page that any reader can apply.

What you will end with: three shared views in every reader’s Reader view list: Engineering (7 open tasks), Support (4 tasks) and Review (3 tasks in review, grouped by team). The page still opens on the author’s starting view.

Defaults, shared views and personal views

Three ways to keep a view
Author defaultsShared viewsPersonal views
Created byPage author, in macro settingsPage author, from a prepared viewAny reader
Stored inThe page’s macro settingsThe page’s macro settingsThe reader’s browser

Use defaults for the view most people need first, and shared views for the alternatives. Readers can apply a shared view, adjust it and save the result as their own personal view.

Step 1: Prepare the Engineering view

Build the view on the published page, exactly as readers should receive it.

  1. Filter Team to Is one of Engineering and Status to Is not one of Done.
  2. Choose Columns and clear Team. Sort Due ascending.
  3. Open Saved views and presentation, enter Engineering in View name and choose Prepare shared view settings.
  4. The status reads Copy the settings into Shared reader views in the macro settings, then publish the page. Select everything in Shared reader views settings and copy it.

Step 2: Publish it

  1. Edit the page and open the Flint Table Filter macro settings.
  2. Set Settings section to Shared reader views.
  3. Replace the entire contents of Shared reader views with the copied text. Choose Save settings, then publish the page.

Preparing a view never edits the page; only publishing the macro settings does.

Step 3: Add Support and Review

The prepared text contains every shared view already published plus the new one, which is why you replace the field each time. Prepare the next view only after the previous one is published.

  1. Reload the published page and choose Reset view. Filter Team to Support, clear Team in Columns and sort Due ascending. Prepare it as Support, then paste and publish as before.
  2. Reload and reset again. Filter Status to Is one of In review and sort Due ascending. In Summary, set Group rows by to Team. In Saved views and presentation, select Group rich rows with subtotals. Prepare it as Review, then paste and publish.

What readers get

Readers open Saved views and presentation and see Author default, Shared: Engineering, Shared: Support and Shared: Review in Reader view, followed by any personal views of their own. Applying a view starts at page one.

Change or remove shared views

  • To update a view, apply it, change it, and prepare it again with the same name. The new version replaces the old one in the prepared text.
  • To remove a view, clear Shared reader views, publish, then prepare again only the views you want to keep.
  • Readers cannot delete shared views. Choosing one and Delete personal view is unavailable.

What to know

  • Shared view settings include search and filter values and are visible to everyone who can read the page. Leave out values that should not be shared.
  • A shared view is not a permission. Every reader can still see every row of the table.
  • If the table’s header cells change, the section reports These views belong to a different table or header layout. Save them again for this table. Rebuild and prepare the views again.
  • Conditional formatting, pinned columns and density can travel in a shared view, even though they cannot be author defaults.
