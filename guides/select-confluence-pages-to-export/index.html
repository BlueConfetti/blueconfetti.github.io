FLINT MARKDOWN EXPORT · HOW-TO

Select exactly the Confluence pages you want to export

Choose pages from a branching tree without accidentally adding, or missing, the pages under them.

Finished result

Five chosen pages from a nine-page tree, including one page that search hid, confirmed by page ID in manifest.json.

Example tree

Release handbook (3001)
  Planning (3002)
    Release calendar (3003)
    Capacity notes (3004)
  Shipping (3005)
    Release checklist (3006)
      Rollback steps (3007)
    Hotfix releases (3008)
  Retrospectives (3009)

The goal: export the release-related pages and the rollback steps under the checklist, but not Planning, Shipping, Capacity notes or Retrospectives.

Walk through the selection

  1. Open Release handbook, choose Apps → Export to Markdown and This page and descendants. All nine pages start selected. Choose Clear selection.
  2. Type release in Search pages…. The tree shows Release handbook, Planning, Release calendar, Shipping, Release checklist and Hotfix releases. Planning and Shipping do not match; they stay visible as parents. Rollback steps is hidden, and branches cannot be collapsed while a search is active.
  3. Choose Select all matches. It adds the four matching titles only: 3001, 3003, 3006 and 3008. Hidden Rollback steps is not added.
  4. Release checklist’s checkbox now shows a mixed state, because one page in its branch is unselected. Tick it: branch checkboxes include descendants, even those hidden by search, so Rollback steps (3007) is added.
  5. Clear the search and turn on Selected only. The tree shows the five selected pages with Planning and Shipping as context. The footer reads 5 pages selected.
  6. Click a title, such as Rollback steps, to inspect it. Inspecting does not change the selection; Prepare page preview prepares that page alone.
  7. Choose Review selection to see the list of selected titles, then export.

Check the result

The manifest lists exactly the selected pages: jq -r '.pages[].page_id' manifest.json prints 3001, 3003, 3006, 3007 and 3008. Planning and Shipping were not selected, so they appear only as directories that keep the hierarchy:

release-handbook/
  release-handbook.md
  release-handbook/
    planning/
      release-calendar.md
    shipping/
      hotfix-releases.md
      release-checklist.md
      release-checklist/
        rollback-steps.md
  all-pages.md
  manifest.json

Useful details

  • Search matches page titles, not page content.
  • With an empty search, the button reads Select all pages.
  • Unticking a branch checkbox removes the whole branch, including hidden pages. Use Selected only to review before exporting.
  • For a space, choose Pages from a space and the space in Space. Confluence folders appear with their page counts; they provide hierarchy rather than exported content.
  • The page list includes only pages you can read, and collecting more than 500 pages stops before selection. See batch exports.
